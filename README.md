🚀 Projects

🎮 Task 1 — Hangman Game

A word-guessing game where the player tries to reveal a hidden word by guessing letters.

Features:

- Random word selection
- Letter guessing
- Tracks incorrect guesses
- Limits incorrect guesses
- Win and lose conditions

Python concepts:

- Random module
- Loops
- Conditional statements
- Strings
- Lists and sets

📊 Task 2 — Stock Portfolio Tracker

A simple program that calculates the value of a stock portfolio based on sample stock prices and user-entered quantities.

Features:

- Accepts stock symbols
- Accepts share quantities
- Calculates individual investments
- Calculates total portfolio value
- Saves portfolio information to a CSV file

Python concepts:

- Dictionaries
- User input
- Arithmetic operations
- Loops
- CSV file handling

Note: Stock prices are sample values for this educational project, not live market data.

🤖 Task 4 — Basic Chatbot

A simple rule-based chatbot that responds to basic messages and greetings.

Features:

- Responds to greetings
- Answers simple questions
- Provides basic help
- Recognizes goodbye messages

Python concepts:

- Functions
- Conditional statements
- Loops
- String manipulation
- User input and output
